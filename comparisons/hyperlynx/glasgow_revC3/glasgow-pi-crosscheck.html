KiPI vs HyperLynx: Glasgow revC3 DC drop

The same board and the same loads solved in KiPI and in HyperLynx PI, compared pin by pin. The copper solutions agree to within HyperLynx's printed resolution. The differences that remain come from how each tool treats series parts and ground.

The solver guide explains how KiPI's DC and electro-thermal solvers work. The user guide explains the setup and results.

  • The copper solutions agree. On +3V3, the +1V2 core and VIO_AUX, every pin agrees within 0.07 mV. Each tool's voltage is measured from its own regulator's pins. HyperLynx prints voltages to 0.1 mV.
  • Series parts read 2.3 % higher in HyperLynx. All 8 parts read the same ratio, wherever they sit on the board and whatever current they carry. At copper's temperature coefficient, a part at 25.8 °C would read this ratio. KiPI uses the resistance it is given, unchanged. With KiPI's series resistances scaled by 1.023, every power pin agrees within 0.15 mV.
  • Ground is modelled differently. HyperLynx holds every regulator's ground pins at 0 V. KiPI lets a linear regulator's ground pins float, and returns all load current to the board's sources. KiPI's ground near the regulators and the FPGA sits 0.18–0.28 mV higher as a result.

Reading ΔV. Every difference on this page is KiPI minus HyperLynx, in millivolts, at a pin HyperLynx reports. Raw compares the absolute voltages. From the regulator's pins subtracts each tool's voltage at the regulator's output pin (for power pins) or ground pin (for ground pins). That removes the difference in where each tool puts 0 V.

Key pins

Series parts

The series parts are ferrite beads, a load switch and resistors, each given a DC resistance in the BUD. KiPI's drop across each part is exactly current × resistance. HyperLynx's drop is 2.3 % higher, and by the same ratio for every part. That includes the two 100 Ω resistors, which dissipate only 0.1 mW, so self-heating can't explain the ratio. The last column but one gives the temperature at which copper's temperature coefficient (0.00393/K from 20 °C) would produce the measured ratio.

Ground

The two tools model ground differently:

  • HyperLynx solves each regulator's rail as a separate analysis. Every regulator's ground pins are held at 0 V and take that rail's return current.
  • KiPI solves one ground carrying every current. A linear regulator's ground pins float and draw only its quiescent current. Load current returns to the board's sources, the USB connector J1 and the VIO_AUX supply pin J5.43, which are both held at 0 V.

KiPI holds J1 and J5.43 at 0 V together, so the two behave as if they were joined off the board. As a result, 115 mA of return current leaves through J5.43, although VIO_AUX itself supplies only 5 mA.

Positive current leaves the ground net at that pin. HyperLynx's values come from the analysis named in the last column, and each is relative to that analysis's own 0 V.

Via currents

These are HyperLynx's highest-current vias, each matched to the KiPI via at the same position. On most vias the two tools agree within a few percent. KiPI reads about 10 % lower on the highest-current +5V vias next to the regulator inputs. The two 0.1 A entries for VIOA and VIOB are connector pin holes, which KiPI reports as pins, not vias.

Thermal

With component heat off, only the copper and via losses heat the board: 5.4 mW, with a peak 0.44 °C above ambient on the +5V trace near FB1. HyperLynx's thermal results aren't part of this comparison.

Component heat. With component heat on, KiPI also heats the board with the 48 mW dissipated in the series parts and the regulators' 0.66 W conversion loss. A temperature comparison needs the same heat sources in both tools.
